# Listening to WAY OUT Radio

Open [WAY OUT Radio](https://wayout.pages.dev/) and press **Ouvir rádio**.
The player shows the current track and displays **Em direto** when a guest
DJ is connected.
Press **Pausar** to stop listening. A compact player appears in the header
as you scroll past the main controls.

See [Programação](https://wayout.pages.dev/#programacao) for upcoming
sets. **Agora** marks a scheduled slot in progress. **A seguir** marks the
next slot. Programme times use mainland Portugal time. AutoDJ plays between sets.

## If the stream is unavailable

Press **Tentar novamente** if playback fails. If the track information is
unavailable, press **Ouvir rádio** to start the stream. Contact the station
operator if you still cannot connect. The programme schedule is available
independently of the audio stream.

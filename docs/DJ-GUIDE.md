# Going live as a DJ

Ask the operator for an AzuraCast DJ account. They will share your username
and password privately. Ask them to add your set to the programme schedule
if you want it listed on the site.

## Start a set

1. Open [Web DJ](https://wayout.pages.dev/dj/) in Chrome or Firefox.
   If it stops working after a station restart, ask the operator for the
   current Web DJ link.
2. Log in, allow microphone access and select your input. Use headphones
   to keep the broadcast out of your microphone.
3. Check that the previous DJ has finished, then start broadcasting.
   Confirm that Web DJ shows you as connected. Listeners hear your input
   in place of AutoDJ while you are live.
4. Stop broadcasting at the end of your set. AutoDJ resumes automatically.

The schedule lets listeners know when to tune in. You still start and stop
your own broadcast in Web DJ.

## Send computer audio to Web DJ

You can route audio from a mixer or a virtual audio device straight into
Web DJ. On macOS, use [BlackHole](https://existential.audio/blackhole/).
On Windows, use [VB-Cable](https://vb-audio.com/Cable/). On Linux, use a
PipeWire or PulseAudio loopback. Send your music app's output to the
device, then select that device as the input in Web DJ.
